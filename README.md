# АКСТЕЛ — лендинг таксопарка

Структура проекта:

- `index.html` — разметка страницы.
- `css/styles.css` — стили и адаптив.
- `js/script.js` — мобильное меню, FAQ и анимации.
- `assets/photos/` — все фотографии проекта.

Все изображения находятся внутри проекта и не загружаются с внешних фотохостингов.

## Текущая версия

- Главный CTA «Подключиться» ведёт в MAX.
- На первом экране сразу доступны MAX, WhatsApp и Telegram.
- На первом экране доступны MAX, WhatsApp и Telegram; MAX выделен визуально сильнее.
- Мобильный фиксированный CTA также ведёт в MAX.

Для локального просмотра откройте `index.html`. Для GitHub Pages загрузите содержимое папки проекта в репозиторий.
