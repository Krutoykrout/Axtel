# АКСТЕЛ — фоторедизайн лендинга

Структура проекта:

- `index.html` — семантическая разметка страницы.
- `css/styles.css` — весь визуал, адаптив и фотокомпозиция.
- `js/script.js` — мобильное меню, FAQ, анимация появления.
- `assets/credits.txt` — источники фотографий.

Откройте `index.html` или опубликуйте содержимое папки в GitHub Pages.

Фотографии подключены по HTTPS с Unsplash, поэтому для их отображения нужен интернет. Это сделано специально, чтобы не раздувать архив тяжёлыми JPG и не использовать SVG-иллюстрации.


## Версия v3
Убраны декоративные стрелочные символы и знаки, уменьшена крупная типографика на desktop и mobile.


## v4
Фотографии заменены на нейтральные автомобильные кадры без иероглифов, вывесок и азиатской городской среды.


## Local photos
All website photos are stored in `assets/photos/`. No photo is loaded from Unsplash or another external image host.
